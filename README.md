# MovieCatalogAPI
Bu proje, BTBS498 dersi kapsamında geliştirilmiş, film ve dizi arşivini yönetmeye olanak tanıyan bir ASP.NET Core Web API uygulamasıdır. Projenin amacı, RESTful web servislerinin temel yapısını, model-service-controller hiyerarşisini ve API test süreçlerini uygulamalı olarak göstermektir.
